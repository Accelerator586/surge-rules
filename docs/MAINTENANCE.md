# 维护记录与审阅入口

每次上游更新的完整增删列表由更新工具写入 `UPSTREAM-UPDATE.md`，并作为更新 PR 的说明。

审阅重点：

1. 查看所有新增的 CN、Apple、Parsec 规则。这些分组在本机选择 DIRECT 时会扩大直连范围。
2. 核对域名归属，避免放行共享云平台和公共后缀；特殊需要尽量使用精确域名。
3. 确认 AI 专属规则仍优先于通用代理规则，未知域名、关键词相似域名继续进入 FINAL。
4. 查看 Actions 的检查结果；需要在真实 Surge 中验证时，先使用独立候选配置，保留原配置备份。
5. 对误匹配修复增加回归案例，再合并 PR。不要为消除一次失败而直接禁用检查。

本仓库没有自动合并流程。定时检查失败时，main 分支和已发布规则保持原版本。
